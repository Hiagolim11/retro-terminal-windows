HACKER TERMINAL RETRO

Emulador de terminal para Windows com efeitos de monitor CRT antigo.

ConPTY + xterm.js para a emulação · WebGL2 para os efeitos.

Inspirado no cool-retro-term, de Filippo Scognamiglio.
